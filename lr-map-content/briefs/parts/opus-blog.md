## Goal: the blog post, consistent with the live site's blog implementation

Produce a new, improved blog entry for the LR Question Type Map that drops straight into GermaineTutoring.com's static-post system: a `BlogPost` module (slug `lr-question-type-map`, replacing the older unpublished version) whose `content` is HTML the live article reader renders well, plus a preview page that shows it with the live site's stylesheets and exports the post's images.

Start from `src/_template-blog.html` (copy it to `src/opus-blog.html`): it already reproduces the live ArticlePage markup with `kit/site-blog.css` (the site's own CSS) and `kit/site-reader.js` (a preview copy of what the site's reader does to a post body). Put the post body between the POST-CONTENT markers and the metadata in `post-meta`, then run `python3 -I tools/blog_to_ts.py src/opus-blog.html` to write `copy/opus-blog.ts`. Read the site's Blog authoring rules and look at how recent posts (for example `7-common-weaken-formats.ts`, `conditional-logic-quantifier-guide.ts` and their `content/` folders) structure resource cards, tables and lists, and match those conventions. Compare with the older unpublished `lr-question-type-map` post and decide what, if anything, from it belongs in the new one (it carries released-question share figures; only use numbers that appear in that source). The share image (`social_image`, 1200×630) is yours to design in the site's Design 09 look; if you add in-article figures, the site's sanitiser allows `img` with `data:image/png|jpeg|webp` sources only, so prefer HTML/CSS figures built from the site's existing classes.

Use `date` `2026-10-15` as a placeholder unless you find a better-supported date. Files: `src/opus-blog.html`, `copy/opus-blog.ts`, and optionally `copy/opus-blog-notes.md` (what you changed and why, and anything Germaine must do to publish: card art, resource page, routes and sitemap entries named in `index.ts`).
