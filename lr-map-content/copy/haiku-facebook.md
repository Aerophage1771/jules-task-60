# Facebook post: answer standards

## Caption

Before you decide whether an LSAT answer is good, decide what it needs to do.

Helpful, necessary, and sufficient are different standards. So are possible, supported, guaranteed, and contradicted.

A statement can strengthen an argument without being necessary to it. It can be necessary without being enough to prove the conclusion. If those standards blur together, the same answer can seem right for three different questions.

The LR Question Type Map organizes all 20 types into six families, with a method and a wrong-answer check for each. Use it to identify the task before choosing, then return to it during review to name the standard your answer missed.

## Image text (answer-standards, 1080×1350)

Eyebrow: LSAT LOGICAL REASONING

Headline: Before you judge an answer, decide what it needs to do.

Panel: Change the Argument
- Helpful: Strengthen: improves the support for the conclusion.
- Required: Necessary Assumption: something the argument requires.
- Sufficient: Sufficient Assumption: makes the conclusion follow.

Panel: Form Your Own Argument
- Possible: The stimulus does not rule it out. That alone proves nothing.
- Supported: Most Strongly Supported: the best support in the stimulus.
- Guaranteed: Must Be True: cannot be false if the stimulus is true.
- Contradicted: Must Be False: cannot coexist with the stimulus.
